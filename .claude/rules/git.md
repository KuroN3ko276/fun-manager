# Git

- Commit nhỏ, mỗi commit một bước/tính năng hoàn chỉnh và build được.
- Message theo Conventional Commits, tiếng Anh:
  `feat: ...`, `fix: ...`, `refactor: ...`, `test: ...`, `docs: ...`, `chore: ...`
- Không commit: `build/`, `.gradle/`, `local.properties`, `.idea/`, `*.apk`, `*.aab`, keystore (`*.jks`, `*.keystore`), `.claude/settings.local.json`. Xem `.gitignore`.
- Không push / force-push khi chưa được yêu cầu.
- Tính năng mới lấy từ `docs/FEATURE_IDEAS.md`; khi làm xong thì tick checkbox trong file đó.
